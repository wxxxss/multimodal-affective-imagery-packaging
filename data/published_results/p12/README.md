# Frozen P12 post-lock interpretation outputs

The files in this directory are non-sensitive, post-lock derived artifacts from the frozen P12 interpretation stage. They summarize coefficient-direction stability, outcome-level evidence grades, candidate design hypotheses, manuscript claim constraints, and provenance.

P12 did not retrain or refit models, reselect hyperparameters, rescore the locked test set, invert score orientation, change labels/features/splits, or select a new threshold.
