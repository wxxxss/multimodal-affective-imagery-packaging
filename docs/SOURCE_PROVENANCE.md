# Source provenance

This public repository is a publication-focused export from the frozen research codebase used for the manuscript.

- Export source snapshot: `1d72e3ba798f93d328c37bfe75b37032b9f21246`
- Export date: 2026-08-29
- Public repository: `wxxxss/multimodal-affective-imagery-packaging`

The public export preserves scientific source files and frozen non-sensitive result artifacts needed to understand the manuscript workflow, while omitting internal collaboration/history files and restricted/raw materials.

## Provenance principle

Where a file is copied from the frozen source snapshot, its scientific content is kept unchanged unless the public repository explicitly documents a publication-facing wrapper or explanatory file. The README and `docs/` files in this repository are publication-facing documentation and are not part of the original analysis execution.

- P8-B: deterministic modeling-ready split
- P9: frozen OpenCLIP and interpretable visual features
- P10: development-only model selection/refit
- P11: one-time locked held-out evaluation

The original project recorded SHA-256 bindings for formal row-level artifacts. Publication-safe copies of row-level derived artifacts that were gitignored in the internal repository still need to be exported separately before PeerJ resubmission; see `docs/DATA_ACCESS.md`.
