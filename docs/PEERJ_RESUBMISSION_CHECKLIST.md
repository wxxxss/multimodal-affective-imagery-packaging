# PeerJ AI Application resubmission checklist

Before resubmission, confirm all of the following:

- [x] Public code repository created.
- [x] Amazon Reviews'23 source URL documented.
- [x] Computing environment documented without inventing unrecorded hardware details.
- [x] Positive-unlabeled semantics documented.
- [x] GPT-5.5 model-assisted validation disclosure documented.
- [ ] Publication-safe derived analysis data exported from the local frozen artifacts and added here or deposited in a DOI-bearing repository.
- [ ] Main manuscript revised to classify the work as an AI Application and to include the computing environment, source-data URL, and explicit preprocessing description.
- [ ] Abstract spells out “area under the receiver operating characteristic curve (AUROC)” at first use.
- [ ] Submission-system Confidential Information confirms: (i) agreement to switch to AI Application; (ii) the single-author submission is intentional.
- [ ] Associated Data entry rechecked after the new code/data repository is available.
- [ ] Revised manuscript and public repository cross-checked for consistent data/code availability statements.

Do not resubmit until the derived-data item is resolved, because PeerJ explicitly requested both code and data for AI Application review.
