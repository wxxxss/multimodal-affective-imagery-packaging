# Label-validation documentation

The manuscript reports a predefined validation sample of 600 sentence-level tasks and 240 product-dimension tasks (840 total). The same tasks were reviewed in two separate ChatGPT (GPT-5.5; OpenAI)-assisted contexts using the same predefined schema without access to the other pass's decisions, followed by rule-guided model-assisted adjudication.

The detailed source protocol and schema used by the study are published in this directory. These materials describe model-assisted review and must not be interpreted as independent human-gold annotation.
